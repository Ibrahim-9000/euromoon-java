# Euromoon – Programming Advanced

## Beschrijving
Dit project is een proof of concept command line Java applicatie voor de treinmaatschappij Euromoon.
De applicatie laat toe om passagiers te registreren, reizen aan te maken, tickets te verkopen en een boardinglijst te genereren.

## Functionaliteiten
- Passagier registreren
- Reis aanmaken
- Trein koppelen aan reis
- Ticket verkopen
- Boardinglijst afdrukken
